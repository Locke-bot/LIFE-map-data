# LIFE map data

Public, versioned OpenStreetMap-derived offline data assets used by LIFE.

The named-place index is built from the [Geofabrik Nigeria extract](https://download.geofabrik.de/africa/nigeria.html) using LIFE's reproducible builder. Data © OpenStreetMap contributors and distributed under the Open Database License (ODbL).

This repository contains no recordings, transcripts, personal location history, API credentials, or application source code.
