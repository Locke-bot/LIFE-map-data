# LIFE map data

Public, versioned OpenStreetMap-derived offline data assets used by LIFE.

The named-place index is built from the [Geofabrik Nigeria extract](https://download.geofabrik.de/africa/nigeria.html) using LIFE's reproducible builder. Data © OpenStreetMap contributors and distributed under the Open Database License (ODbL).

`ibadan-overture-places.sqlite` is a separate broad-Ibadan augmentation pack
built from the Overture Maps Foundation Places release `2026-11-18.0`. It keeps
GERS IDs, taxonomy, confidence, addresses and provider provenance. Overture data
is provided under its per-source CDLA Permissive 2.0 and Apache 2.0 terms; see
[Overture attribution](https://docs.overturemaps.org/attribution/). The datasets
remain separate and LIFE combines them only at query and display time.

This repository contains no recordings, transcripts, personal location history, API credentials, or application source code.
